## О чем страница

Для сетей доставки, у которых свои курьеры. В час пик и в плохую погоду курьеров не хватает, а поменять им оплату быстро не получается. Лендинг показывает, как в Goulash.tech оплату меняют за минуты и курьеры выходят на смену.

Семь разделов: Главная → Проблема → Пульт → Продукт → Кейсы → Внедрение → Заявка.

- **Пульт.** Погода, ставка за заказ, премия за выход. Курьеры на карте выходят на смену, зона «успеваем вовремя» растёт, время ожидания падает. Все числа условные, на странице это подписано.
- **Час пик.** Три сцены из живых линий: кухня с готовыми заказами, пустые термосумки, гостья с телефоном.
- **Кейс.** Портрет Дмитрия Инякина из 218 тысяч зерен, под курсором они смазываются.
- **Заявка.** Ошибки и тексты как на форме goulash.tech. Форма демо: ничего не отправляет и не сохраняет, это сказано на экране успеха.

## Как сделано

- Без фреймворков и сборки: один `index.html`, стили внутри, скрипты в `js/`
- Карта Екатеринбурга по данным OpenStreetMap рисуется на canvas
- Сцены: картинки сгенерированы в GPT Image, потом скриптом превращены в поле направлений, по которому текут линии (`data/field-*.json`)
- Цвета, шрифт и кегли — токены из дизайн-системы Goulash.tech (`css/tokens.css`), макеты и компоненты в Figma
- Адаптив от 280 px до широких экранов
- Быстрый первый экран: шрифт лежит рядом с сайтом и грузится заранее вместе с картой, сцены и портрет подгружаются после первого кадра

## Запустить у себя

```bash
python3 -m http.server 4310
```

Открыть http://localhost:4310

## Служебные адреса

- `?pin=console` — один раздел без прокрутки (`top`, `evening`, `console`, `system`, `cases`, `move`, `lead`)
- `?fail` — ошибка отправки формы
- `?bare&scene=0` — только карта и сцена, для кадров в Figma

## Выкладка

`python3 scripts/deploy_beget.py` — заливает файлы на Beget в папку `/goulash/`. Нужны `BEGET_LOGIN` и `BEGET_API_PASSWORD` в окружении. GitHub Pages обновляется сам после пуша в `main`.
